The compiler in brief

onda is a Rust compiler of about 400,000 lines. The frontend (PEG grammar) and the semantic analysis (typing, overloads, generic specialization, lowering of processors and graphs) produce a typed, validated MIR: structured control flow, explicit storage and effects, integer range facts, bounds proofs, memory origins for aliasing, loop analyses. Two backends consume it: LLVM (ORC JIT and AOT objects, O3, noalias attributes and alias scopes, 64-byte alignment, SLEEF linked into the code) and Binaryen (Wasm). Block size and sample rate are compile-time constants.

The code quality comes from these proofs handed to LLVM, not from DSP-specific optimizations: onda has no equivalent of Faust's signal normalization. The code therefore stays close to what the author writes. An array of delay lines gets vectorized, eight separate variables would not. Conversely, Faust optimizes forms the author did not factor, but can also undo a factorization (zita's FWHT).

Method

Machine
macOS, with the benchmark thread at user-interactive QoS.
Onda
AOT objects built with --emit obj --target-cpu host -b 256 --sr 48000, with and without --fast-math, called through onda_process.
Faust C++
faust -lang cpp 2.95.1 (-scal and -vec -vs 32) with the libraries of the faustlibraries checkout, Apple clang -O3 -mcpu=native, three contracts: default (FMA), -ffp-contract=off, -ffast-math; plus -vec with -fveclib=Accelerate.
Faust LLVM
libfaustwithllvm (2.95.1), createDSPFactoryFromFile, opt −1 (max), -scal and -vec -vs 32, plus -scal with a fixed SR.
Faust cert-4
Branch master-dev-certification-4 (106dda74a, 2.92.5), exported with git archive and built with the Makefile of build/. -lang ocpp in IEEE (-ffp-contract=off), with the default contract and with -ffast-math; options elected by fcautotool compiled with -O3 -ffast-math, as during the election.
Fixed SR
Copy of the faustlibraries libraries where platform.lib defines SR = 48000.0 (faust looks for platform.lib next to maths.lib first, hence the full copy).
Harness
One executable per program links the 15 engines, with 16 input and output channels; same buffers, same input (deterministic white noise, 64 blocks cycled), 2000 warm-up blocks, then 21 rounds in shuffled order. Median time per frame reported.
Corpus
%%NPROG%% paired Onda and Faust implementations, including oscillators, filters, delays, and physical models.
Limits
One machine, fixed parameters, and one block size.
